# Pilot 실제 입력 검증 기록

## 조건과 범위

- 검증일: 2026-10-18, AI 이슈 #64.
- pilot 10건을 원본 전체 페이지와 대조해 라벨 v3.1로 검수했다.
  검수 방법은 AI 보조 시각 검수이며 사람 여러 명의 합의 라벨링이 아니다.
- BE OCR은 앱, 로그인, DB 저장 없이 일괄 추출했다. 10건 모두 SUCCESS이며 PARTIAL/FAILED는 0건이다.
  PDF 9개와 JPG 1개, 총 13페이지다. PDF 중 1개는 기존 HWP 내보내기 파일이다.
- BE 기준일은 2026-10-18이다. 연도 없는 후보가 기준 연도로 잘못 정규화되어도 수정하지 않았다.
- 실제 OCR, 후보, 기준일을 input에 연결하고 정답 expected와 분리했다. 원본 SHA-256과 후보 위치를 검증했다.
- 모델 조건은 gpt-4.1, 원본 detail=high, 샘플 간 40초 대기다.
  PDF는 Files API의 원본 PDF 입력이며 detail 옵션은 이미지 입력에 적용된다.
- 원본/실제 OCR/전체 예측/인증 정보는 커밋하지 않는다. 로컬 결과 위치는 아래에 기록한다.
- 운영 프롬프트와 BE 날짜 추출기는 이번 검증에서 수정하지 않았다.

## OCR 전용 모델 결과

- 실제 모델 분석 10건 완료, 호출/응답 검증 실패 0건, 첨부 수 0건.
- 항목 F1 0.6471, datetime accuracy 0.6786, checklist F1 0.3200.
- 날짜/시간 정확도는 매칭된 항목 기준이며 문서별 평균이다. 항목 매칭이 없는 문서는
  해당 정확도에서 제외되므로 항목 F1과 metric_sample_counts를 함께 봐야 한다.
- 자동 F1은 의미 정답률이 아니다. pilot_006은 두 휴업 날짜를 정확히 추출했지만
  첫 항목의 제목 표현이 달라 자동 매칭에 실패했다. 준비물을 합치거나 나누는 차이도
  체크리스트 점수에 영향을 준다. 점수를 맞추기 위해 라벨을 모델 응답에 맞춰 변경하지 않았다.

## 완료 판단

#64의 완료는 실제 입력 연결, 라벨 기준 정리, 오류 검출 및 재현 가능한 평가 경로의 검증이다.
모델 분석 품질이 모두 해결되었다는 뜻은 아니다. 위의 연도 충돌, 시각/행사 누락, 일반 권고 과잉 추출,
요약 조건 보존과 자동 의미 매칭 한계는 후속 개선 대상으로 남긴다.
이번 검증을 통과한 것으로 보고 운영 프롬프트까지 수정하거나 기존 품질 문제를 해결 완료로 처리하지 않는다.

자동 점수와 원본 대조 관찰은 구분한다. 제목/행동의 표현 및 묶음 차이를 줄이는 후속 평가 기준을
추가한다면 라벨/평가기 버전을 올리고 저장된 예측에 먼저 동일 기준으로 재채점한다.
점수를 높이기 위한 정답 사후 변경이나 불필요한 API 재호출은 하지 않는다.

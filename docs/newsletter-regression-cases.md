# 가정통신문 회귀 평가 기준

현재 구현은 strict schema 단일 분석 호출과 날짜 후보/원문 날짜 일치 후처리이다.
2단계 원문 재검토는 품질 개선이 확인되지 않아 제외했다.
단위 테스트는 지침 존재, 스키마 구성, 후처리와 평가 도구를 검사한다.
아래 실제 모델 정확도를 보장하지 않는다.

| 입력 | 기대 결과 |
| --- | --- |
| 준비물 안내, 발행일 2026-09-02만 존재 | reminder/missing. 발행일 제외. 공책, 연필, 지우개, 풀, 가위, 색연필, 색사인펜, 자 보존. 학교 지원 물품 제외. 학년/학급별 상이 조건 유지 |

## 경계 조건

- 준비물 안내에 실제 준비 기한 추가: 후보가 있으면 deadline/confirmed, 없으면 ambiguous.
- 본문 기한과 발행일이 같은 날: 본문 기한 근거로 정상 일정 유지.
- 학교 제공 물품만 있고 가정 행동 없음: items=[].
- 같은 물품이 학교 지원과 가정 구매 양쪽에 있음: 가정 구매 요구 유지.
- 다음 해 일정이 명시된 문서: 문서 첫 연도를 모든 사건에 일괄 적용하지 않음.
- 과거 날짜의 안내를 늦게 업로드: referenceDate만으로 사건 삭제하지 않음.

## 평가 시 주의

날짜 존재만 검사하지 말고 유형, 시각, 필수 행동과 조건, 잘못 추가한 행동도 검사한다.
문구 정규식이나 정확한 항목 개수만으로 전체 정확도를 단정하지 않는다.
학교폭력 예시 화면 날짜는 PDF 텍스트 추출에서 누락되어 수동 전사로 추가한 조건이다.
원문이 없는 현장체험학습 뒷면 안전교육 내용을 창작하지 않는다.
연도 충돌 조건은 실제 BE 요청이 아닌 합성 후보다.
현재 모델의 실패 내역과 배포 전 연동 조건은 newsletter-issue-53.md를 참고한다.

# 가정통신문 원본 첨부 평가

가정통신문 원본(PDF/이미지)을 OCR 텍스트와 함께 AI 분석에 첨부했을 때 결과가 어떻게 달라지는지 기록한다.
관련 문서: [newsletter-issue-53.md](newsletter-issue-53.md), [newsletter-prompt-changes.md](newsletter-prompt-changes.md)

## 평가 방법

- 도구: 로컬 `newsletter-prompt-check/run_suite.py` (레포 밖, 실제 학교 문서가 포함되어 커밋하지 않음)
- 케이스: `suite-cases.json`의 8개 (wellbeing, fieldtrip, survey, album, album-year-conflict, supplies, family-missing-end, family-complete)
- 원본 없이: `run_suite.py --live --repeat 1 --delay-seconds 40`
- 원본 포함: `run_suite.py --live --repeat 1 --with-documents --delay-seconds 40`
  - 서버와 같은 흐름: Files API 업로드 → 원본 첨부 프롬프트 → 원본 기준 날짜 검증 → 파일 삭제
  - 원본: `originals/<케이스>/` (album만 PNG, 나머지 PDF)
- 주의
  - 케이스 입력 텍스트는 대부분 PDF 텍스트 추출/수동 전사라 실제 OCR 오류가 적다. 실제 OCR 입력은 family 두 케이스뿐이다.
  - 자동 검사는 부분 검사이며, 결과는 `report.md`로 수동 확인이 필요하다.
  - 각 조건 1회 실행이라 실행마다 결과가 달라질 수 있다.
  - OpenAI 분당 토큰 한도(429)를 피하려고 호출 사이에 40초 대기를 둔다.
  - 아래 2026-09-24 자동 통과 수치는 당시 텍스트 전용 기준으로 채점한 기록이다. 2026-09-28 로컬 평가 도구에서 원본 포함 모드의 별도 기준을 추가했으며, 과거 수치를 새 점수처럼 인용하지 않는다.

## 관찰

### 1차 (프롬프트 fe61a432)

- 원본 첨부는 금액, 신청 조건, 요약의 구체성 같은 내용 보존에 효과가 보였다.
- 원본에서만 읽은 날짜(`DOCUMENT_ONLY_DATE`)는 한 번도 발생하지 않았다.
- album-year-conflict에서 모델이 연도 충돌을 확인 질문에 적고도 잘못된 후보(2026-12-30)를 confirmed로 반환했다.
- 입력 토큰은 평균 약 40% 증가했다.

### 2차 (프롬프트 f6c258d7)

- 원본 우선 날짜 규칙이 실제로 작동했다. 원본 포함에서 `DOCUMENT_ONLY_DATE`가 3개 케이스 4개 항목에서 발생했다.
  - album-year-conflict: 틀린 후보 연도(2026) 대신 원본 연도(2025)로 확정
  - family-missing-end: 후보에 없던 마감 9/18 15:00을 확정
- 원본 포함에서 틀린 연도가 캘린더에 들어가는 문제는 해결됐다.
- 원본 없이는 album-year-conflict 납부를 여전히 2026-12-30으로 확정했다.
  이번에는 확인 질문도 쓰지 않아 "confirmed와 확인 요청 동시 사용 금지" 규칙과는 무관하게 발생했다.
  원문은 '30일(화)'인데 2026-12-30은 수요일이라 요일 검사로 코드에서 잡을 수 있다.
- family-complete에서 후보가 있는데도 후보를 고르지 않고 원본 경로를 사용했다. 날짜는 맞아 사용자 영향은 없지만 규칙 1(후보 우선)이 약하게 작동한다.
- fieldtrip은 두 모드 모두 안전 안내문 읽기를 별도 항목으로 분리해 항목 개수 검사에 실패했다. P3(읽기 요구 구분) 변경의 영향인지 확인이 필요하다.
- 프롬프트가 길어져 원본 없이 입력 토큰이 약 1,100 늘었다. 원본 첨부 시 증가율은 1차와 비슷한 약 40%다.

## 다음 단계

2026-09-28 기준 1, 3, 4번은 오프라인 코드와 로컬 평가 기준에서 처리했다.
fieldtrip의 안전 안내문 읽기는 행사 checklist 또는 날짜 없는 reminder를 모두 허용한다.
요일 불일치 후보는 `SOURCE_WEEKDAY_CONFLICT`로 ambiguous 처리한다.
원본 첨부 `low` 5조건 각 1회 결과에서 album-year-conflict는 두 날짜 모두 ambiguous로 남아,
입력 토큰 절감만으로 `low`를 기본값으로 채택하지 않는다. 모델 반복 안정성과 BE 연동은 미검증이다.

1. 완료: 원본 없이 분석할 때 요일 불일치 날짜를 ambiguous로 강등
2. 원본 첨부 시 후보가 원본과 같으면 후보를 선택하도록 규칙 1 보강 검토
3. 일부 완료: fieldtrip rubric 정합성 반영. P3 영향은 반복 평가 후 판단
4. 완료: family-missing-end, album-year-conflict에 원본 포함 모드용 채점 기준 추가
5. 주요 케이스는 `--repeat 2~3`으로 반복 확인

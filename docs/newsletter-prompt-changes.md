# 가정통신문 프롬프트 수정 기록

data/newsletter-labels의 001~020 재라벨링 과정에서 확인된 판단 기준을 시스템 프롬프트에 반영한 기록이다.
각 항목은 재라벨링에서 확정한 정답과 프롬프트의 지시가 어긋나던 지점이다.
라벨과 프롬프트가 같은 기준을 따르도록 맞추는 것이 목적이며, 실제 모델 정확도 개선은 측정으로 확인해야 한다.

수정 대상 파일: `app/services/newsletter_prompt.py`의 `_build_system_prompt`

## 이미 반영되어 있던 항목

- 원본 문서 첨부 기능(`_DOCUMENT_USAGE_PRINCIPLES`)의 4번 규칙이 요일·학년도 충돌 시 ambiguous를 다룬다.
  다만 원본이 첨부되지 않은 요청에는 적용되지 않으므로 P6과 P12를 날짜 판단 원칙에 별도로 추가했다.
- 상대 날짜만 있는 절차(005 교외체험학습)는 기존 "행동은 있지만 기한이 없으면 reminder/missing" 규칙으로 처리된다.

## 주의해서 관찰할 항목

- P4와 P16, P9는 "원문에 있는 것을 항목으로 만들지 않는다"는 방향이다.
  과하게 작동하면 복수 사건 누락이나 필요한 조건부 행동 삭제로 이어질 수 있다.
  측정에서 누락이 늘어나는지 우선 확인한다.
- P5는 "마감일이 없으면 개시일을 confirmed"이고, 기존 규칙은 "종료일 후보가 없으면 시작일을 쓰지 않는다"이다.
  두 규칙의 경계를 모델이 혼동하는지 확인한다.
